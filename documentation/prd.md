# Product Requirements Document (PRD)

| Field | Value |
|-------|--------|
| **Feature** | Add Movie to Favorites |
| **Document** | Business PRD |
| **Owner** | Product Management |
| **Status** | Draft for demo |
| **Related Epic** | EPIC-50: User Watchlist & Favorites System |

---

## 1. The Idea

Users want a way to save movies they like so they can watch them later without searching for them again.

---

## 2. Goal

Increase engagement and retention by letting logged-in users build a personal “My List” of favorite movies with a single click from any movie card.

---

## 3. What the PRD Says

1. **Add a heart/bookmark icon** on every movie card.
2. **When clicked**, save that movie to the user’s personal **My List** page.
3. **Keep it fast and simple** so the user stays engaged.

---

## 4. Success Criteria

| Criterion | Target |
|-----------|--------|
| Discoverability | Heart icon visible on every movie card |
| Save action | One click adds the movie to My List |
| Speed perception | Interaction feels instant; user stays on the browsing flow |
| My List | User can open a dedicated page and see all saved movies |

---

## 5. Out of Scope (for this PRD)

- Social sharing of favorites
- Collaborative / family watchlists
- Recommendations based on favorites
- Guest (logged-out) favorites

---

## 6. Next Step in Traditional SDLC

Product hands this PRD to engineering. A Tech Lead / Architect produces a **Technical PRD** (see [`tech-prd.md`](./tech-prd.md)) before stories and tasks are written.
